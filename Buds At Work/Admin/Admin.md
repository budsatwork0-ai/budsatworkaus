## Why this structure exists

The admin page was originally a "financial command centre." It has been upgraded to a **full-spectrum operations command centre** covering 12 domains. Each domain now has:

- A card on the `/dashboard` Domain Command Panel (at-a-glance stats + click-through)
- A quick action button for the most frequent task in that domain
- A dedicated Obsidian note with SOPs, automation opportunities, and links

This means zero context-switching — everything visible from one screen, deep-dives one click away.
