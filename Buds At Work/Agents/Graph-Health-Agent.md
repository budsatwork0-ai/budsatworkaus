# Graph Health Agent

## Purpose

Keeps the Obsidian + Graphify architecture graph organised and connected.

## Responsibilities

- find orphan notes
- fix disconnected systems
- connect runtime notes
- connect process notes
- reduce graph fragmentation
- strengthen architecture hubs
- detect stale notes
- detect duplicate concepts

## Main Queries

```bash
graphify query "orphan systems"
graphify query "weakly connected nodes"
graphify query "highest dependency concentration"
graphify query "cross-community bridges"
```
